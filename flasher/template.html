3Flash

⇅Back up or clone a board (optional)

A backup is an exact copy of the whole board: the firmware, your ROM, every disk in the library and the Wi-Fi settings. Restore it later, or write it onto a second %%SHORT%% to make a clone. Connect first (step 2).

A backup holds your Wi-Fi password and your Apple ROM, so keep the file to yourself.

4First start

The board restarts by itself (%%RESTARTHINT%%). Then join the Wi-Fi hotspot %%AP%% (password heltecmac), open http://192.168.4.1, pick your home network, and upload your ROM and a disk on the page it shows next.

5Watch the board start (optional)

Shows what the board prints while it starts: Wi-Fi, memory and whether the Mac started. Useful if it gets stuck. Click Disconnect above first if you're still connected for flashing.
